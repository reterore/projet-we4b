Bienvenu dans le projet Moodneuille développée par Ivann Vasic et Lucas Vigny,
en Angular (frontend) et Node.js avec Express (backend), avec MongoDB comme base de données.

**Prérequis**
- Node.js (version ≥ 16)
- npm (inclus avec Node.js)
- Angular CLI
- MongoDB 

Le projet est structurés en 2 dossiers backend et frontend.

**Installation et éxécution**

**Backend (Express + MongoDB)**

- Accédez au dossier backend 

- Installez les dépendances nécessaires :
npm install

- Avant de lancer le backend, exécutez le script de seed (pour insérer des utilisateurs, cours, etc.) :
node seed.js

- Lancez le serveur :
node index.js

Le backend sera disponible sur http://localhost:3000.

**Frontend (Angular)**

- Accédez au dossier frontend

- Installez les dépendances Angular
npm install

- Lancez l’application Angular:
ng serve

L'application Angular sera disponible sur http://localhost:4200.
